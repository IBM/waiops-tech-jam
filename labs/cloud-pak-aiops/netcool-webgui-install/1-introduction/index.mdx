Netcool/OMNIbus and Netcool/Impact are used widely around the world and invariably end up as a needed component set within any operations management deployment. Netcool deployment skills therefore are essential for deploying this key set of components.

Netcool/WebGUI is the UI component of Netcool/OMNIbus and the installation of it is covered in this lab.

### Lab content

In this lab, you will perform the following tasks:

- Install needed operating system packages
- Set up the user, group, and environment
- Unpack the software
- Install IBM Installation Manager
- Install Netcool/OMNIbus, then configure and start an ObjectServer and a Probe
- Install Netcool/WebGUI, then integrate it with the ObjectServer as a sources of events
- Configure Netcool/WebGUI to auto-start on machine boot
- Log into the Netcool/WebGUI console

The lab should be executed in the numbered order that you see on the left side of the screen in the navigation pane as sections depend on work completed in prior sections.

### Software versions

Netcool/WebGUI runs on an IBM WebSphere platform running IBM Jazz for Service Management (Jazz). In this lab, we will install the following set of components:

* IBM WebSphere Application Server 9.0.5.27
* IBM SDK Java Technology Edition 8.0.8.60
* Jazz for Service Management extension for IBM WebSphere 9.0 1.1.3.27
* IBM Dashboard Application Services Hub 3.1.3.27
* IBM Tivoli Netcool/OMNIbus Web GUI 8.1.0.41
* Netcool Operations Insight Extensions for IBM Tivoli Netcool/OMNIbus Web GUI 8.1.0.41
