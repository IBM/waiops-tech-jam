# OpenTelemetry foundations and collectors

This lab is an introduction to OpenTelemetry (OTel) and OTel collectors. By the end of the lab you will be able to answer the following questions:

- What does all the OTel jargon mean?
- How does OTel work with the Instana Agent?
- If I add OTel to one of my services, how is the telemetry extracted and how does it end up in Instana?
- What is the difference between the Instana collector (IDOT) and the community collector? Which should I use?

## What this lab includes

In this lab we will:

- Explain the basics of OpenTelemetry and the relevant components to Instana.
- Build multiple telemetry pipelines on a Linux VM with various configurations for sending to Instana.
- Explore, configure, troubleshoot and compare the two most relevant OpenTelemetry Collector distributions to Instana:
  - **OpenTelemetry Collector Contrib** (`otelcol-contrib`): The community distribution.
  - **IDOT** ([Instana Distribution of OpenTelemetry Collector](https://github.com/instana/instana-otel-collector)): An IBM curated distribution with Instana specific additions.
